# Тестирование

## Автоматические тесты
```bash
NEXUS_SINGBOX_BIN=/path/to/sing-box-1.14.4 tools/run_tests.sh
```
Перед тестами раннер загружает **все** скрипты `scripts/`, `scenes/`, `addons/` — синтаксическая ошибка в любом из них проваливает прогон. Без `NEXUS_SINGBOX_BIN` (или без `openssl`/`curl`/`python3`) проверки ядром и сквозные тесты помечаются **SKIP**, а не «пройдено».

Хостовая сборка sing-box для тестов: в каталоге исходников v1.14.4
`go build -tags with_gvisor,with_quic,with_wireguard,with_utls,with_clash_api,badlinkname,tfogo_checklinkname0 -ldflags "-checklinkname=0" ./cmd/sing-box`.

```
89 tests, 89 passed, 0 failed, 0 skipped
```

### Ошибки, найденные тестами и исправленные
- Пользовательское название подписки перезаписывалось заголовком `profile-title`.
- BOM внутри содержимого подписки не удалялся.
- Полная JSON-конфигурация без TUN и без серверов принималась.
- Первые сквозные тесты проходили ложно: `curl` обходил SOCKS-прокси из-за `NO_PROXY` окружения; это обнаружил негативный тест, исправлено (`--noproxy ''`).
- Отмена во время запроса разрешения не прерывала сценарий подключения.

### Что автотесты НЕ покрывают
Нативный слой Android (VpnService, TUN, protect, уведомления, разрешения, межпроцессное взаимодействие) — собран (Kotlin компилируется, APK собирается, манифест проверен `aapt2`), но не исполнялся: в среде сборки нет устройства и KVM для эмулятора.
