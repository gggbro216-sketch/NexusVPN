# Решение проблем

| Симптом | Причина / решение |
|---|---|
| «VPN-подключение пока реализовано только для Android» | запущено на ПК или в редакторе — нативного адаптера нет; импорт и TCP-проверка работают |
| «Android plugin NexusVpnBridge is missing from this build» | экспорт без Gradle-сборки или без AAR: включите «Use Gradle Build», проверьте `addons/android_vpn_bridge/bin/` и что плагин редактора включён |
| «ядро отклонило конфигурацию: …» | параметр не поддерживается sing-box 1.14; откройте сервер → «Проверить ядром», текст ошибки — от ядра |
| «сервер не отвечает: запрос через прокси не прошёл» | ядро запустилось, но HTTP-запрос через сервер не прошёл: неверные учётные данные, блокировка, неверный SNI/REALITY-ключ, время на устройстве. Журнал sing-box в «Диагностике» (уровень `debug`) |
| «разрешение на VPN не выдано» | системный диалог отклонён или другой VPN «Постоянный»; разрешите в настройках Android |
| Подключение с правилами geoip/geosite не стартует | первый запуск скачивает `.srs` с GitHub через прокси; если GitHub недоступен — уберите эти правила или режим «раздельная» |
| «Подписка: HTML-страница» | неверный URL или нужна авторизация; откройте адрес в браузере |
| «Clash/Mihomo YAML не поддерживается» | запросите у провайдера ссылку в формате base64 / sing-box (часто параметр `?flag=sing-box` или другой User-Agent в настройках подписок) |
| «XHTTP is not implemented by sing-box 1.14» | у сервера транспорт XHTTP; попросите вариант TCP/WS/gRPC/HTTPUpgrade |
| Не обновляются скорость/IP | проверка IP отключена или сервис недоступен; в фоне статистика не обновляется (данные подтянутся при возврате) |
| После переустановки «Данные профилей недоступны» | ключ Android Keystore удалён вместе с приложением; восстановите резервную копию (экспорт делается вручную) |
| Gradle: HTTP 429 от Maven Central | лимит запросов; зеркало через init-скрипт (BUILD_ANDROID.md) |
| Экспорт: «Android build template not installed» | `tools/build_apk.sh` или Project → Install Android Build Template |

Журналы: «Настройки → Диагностика»: фильтры уровня (Debug/Info/Warning/Error) и источника (приложение/sing-box), копирование, отчёт без секретов. Уровень журнала sing-box применяется при следующем подключении.

Сбор logcat: `adb logcat -s NexusVpnService NexusBoxCore NexusCoreClient NexusVpnPlugin NexusNetworkMonitor godot`.
