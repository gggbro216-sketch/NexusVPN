# NEXUS VPN

VPN-клиент для Android на **Godot Engine 4.7** (GDScript) с сетевым ядром **sing-box 1.14.4** (libbox), работающим внутри системного **Android VpnService**.

> Статус: **частично готов** — см. раздел «Состояние проекта». Код собран в APK, конфигурации проверены настоящим ядром sing-box, протоколы проверены сквозными тестами на хосте, **но приложение ещё не запускалось на реальном Android-устройстве** (в среде разработки нет устройства и KVM для эмулятора).

## Возможности

- Подключение через sing-box в `VpnService` (TUN), отдельный процесс `:vpn` — VPN продолжает работать, когда интерфейс закрыт.
- Состояния: Отключено → Подготовка → Запрос разрешения → Подключение → **Подключено только после успешного запроса через сервер** → Переподключение / Остановка / Ошибка.
- Импорт: вставка ссылки, несколько ссылок, base64, файл (TXT/JSON/WireGuard `.conf`), QR (камера через Google code scanner или из изображения через ZXing), подписки по URL, JSON sing-box (как набор серверов или полная конфигурация).
- Протоколы: VLESS (TCP/REALITY/TLS/WS/gRPC/HTTPUpgrade/HTTP2/QUIC, Vision), VMess, Trojan, Shadowsocks (AEAD, 2022, obfs/v2ray-plugin), Hysteria2, TUIC, WireGuard, AnyTLS, SOCKS, HTTP, SSH, Snell (через JSON). Полная таблица — [docs/PROTOCOL_SUPPORT.md](docs/PROTOCOL_SUPPORT.md).
- Подписки: определение формата, base64/ссылки/JSON sing-box, `subscription-userinfo`, `profile-title`, автообновление, сохранение пользовательских названий и избранного, без удаления серверов при ошибке.
- Проверка серверов: настоящая задержка через прокси (ядро sing-box, временная сессия без TUN) и отдельно — TCP-доступность порта; выбор лучшего сервера.
- Маршрутизация: весь трафик / раздельная (страна напрямую) / только выбранное / напрямую / пользовательские правила (домены, IP/подсети, порты, geosite/geoip), визуальный редактор, предупреждения о конфликтах.
- DNS через прокси (DoH/DoT/DoQ/DoH3/UDP), прямой DNS, стратегия IPv4/IPv6, перехват DNS в туннеле.
- Раздельное туннелирование по приложениям (Android `addAllowedApplication`/`addDisallowedApplication`).
- Статистика от счётчиков ядра, история сессий, диагностика с маскировкой секретов, отчёт без секретов.
- Зашифрованное хранение профилей (AES-256, ключ обёрнут Android Keystore), резервные копии, миграции схемы.
- Тёмная и светлая темы, оригинальный интерфейс.

## Быстрый старт

```bash
# тесты (Godot 4.7.2 в PATH; NEXUS_SINGBOX_BIN включает проверки реальным ядром)
NEXUS_SINGBOX_BIN=/path/to/sing-box tools/run_tests.sh
# APK
tools/build_apk.sh debug            # build/NexusVPN-debug.apk
```

Подробно: [docs/BUILD_ANDROID.md](docs/BUILD_ANDROID.md).

## Как добавить VLESS-ссылку
1. Скопируйте ссылку `vless://…`.
2. На главном экране нажмите «+» → «Вставить» → «Добавить» (или «Серверы» → «+»).
3. Сервер появится в списке и станет активным, если активного ещё нет. Неподдерживаемые параметры (например, XHTTP) показываются как понятная ошибка, игнорируемые — как предупреждения в «Диагностике».

## Как подключиться
1. Выберите сервер (вкладка «Серверы» — нажатие на строку).
2. На главном экране нажмите большую кнопку. При первом подключении Android покажет системный запрос на создание VPN — подтвердите.
3. Состояние «Подключено» появляется только после успешного HTTP-запроса через сервер (`generate_204`). Ниже отображаются внешний IP (если включено в «Сеть»), время, скорость и объём.
4. Отключение — повторное нажатие или кнопка «Отключить» в уведомлении.

## Известные ограничения

- **Нет проверки на реальном устройстве** (см. выше).
- **XHTTP/SplitHTTP, mKCP, VLESS encryption (ML-KEM)** — не реализованы в sing-box 1.14, такие ссылки отклоняются с объяснением.
- **NaiveProxy, Tailscale, OpenVPN, OpenConnect** — есть в sing-box, но не включены в эту сборку libbox (размер). Включаются тегами в `tools/build_libbox.sh`.
- **Kill Switch** — средствами приложения невозможен; используется системная «Постоянная VPN» + «Блокировать соединения без VPN» (кнопка в настройках «Подключение»).
- **Clash/Mihomo YAML и Xray JSON** подписки распознаются, но не импортируются (сообщение об ошибке).
- **Настольные платформы** — UI, импорт и TCP-проверка работают, VPN-адаптер не реализован (честно отображается как недоступный).
- Скорость/статистика в фоне не обновляется (Godot приостанавливает интерфейс); ядро продолжает считать трафик, данные подтягиваются при возврате.
- Язык интерфейса — только русский.
- Размер APK: ~93 МБ (arm64 + armv7), из них ~60 МБ — libbox на ABI (сжато).

## План развития
1. Проверка на устройствах Android 8–16, исправление найденных проблем.
2. Сплит-APK/AAB по ABI, уменьшение размера (теги libbox).
3. Импорт Clash YAML, экспорт подписок, синхронизация.
4. Адаптеры Windows/Linux (sing-box как отдельный процесс с TUN/wintun), macOS (Network Extension).
5. Локализация, виджет/быстрые настройки (Quick Settings tile).
